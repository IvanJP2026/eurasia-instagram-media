# Eurasia Japan · Instagram media

Images of posts published on Instagram [@eurasijp](https://www.instagram.com/eurasijp/) by
[Eurasia Japan](https://eurasiajp.com), Tokyo. The Instagram API fetches post images from this repository.
Media only: one folder per carousel, slides in order. Prices shown are prices on eurasiajp.com at the time
of posting.
